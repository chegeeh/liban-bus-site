# Liban Bus Ltd – static site

Plain HTML/CSS/JS. No build step.

## Publish on GitHub Pages
1. Create a repo and upload the *contents* of this folder to the repo root (index.html must be at the root).
2. Repo → Settings → Pages → Source: "Deploy from a branch" → `main` / `(root)` → Save.
3. Your site appears at https://USERNAME.github.io/REPO/ in a minute or two.

Custom domain: add a file named `CNAME` containing `libanbusbooking.com` and point your DNS to GitHub Pages.

## Edit
- Routes, fares, departure times: `js/data.js` (then update the cards in `routes.html`)
- WhatsApp / phone number: search for `254107080689` and `0107 080 689`
